
# Neural Network Animations

Cinematic neural network visualizations built with Python and Manim.

## About

This project explores how mathematical and AI concepts can be visualized through code.

## Animations

- `network.py` — Basic neural network visualization
- `neural_flow.py` — Animated signal propagation
- `neural_cinematic.py` — Cinematic particles, glow, and camera movements

## Technologies

- Python
- Manim Community
- NumPy

## Installation

```bash
pip install -r requirements.txt
```

## Run

```bash
manim -pqh neural_cinematic.py CinematicNeuralNetwork
```

## Note

The animations are conceptual visualizations, not simulations of actual neural network inference.
